Aset DPL Monitoring Apps Divisi NSD / Branch Operations Support
Petunjuk Pengisian Aplikasi
  1. Pilih tab Tabel Ringkasan Aset untuk melihat daftar keseluruhan Aset Dalam Penyelesaian (DPL).
  2. Gunakan Filter Wilayah di bagian atas untuk menyaring data per kantor wilayah.
  3. Klik tombol Update pada kolom Aksi untuk melengkapi Unit Pelaksana Pengadaan, Progress Proyek, dan Tindak Lanjut.
  4. Gunakan tombol View Detail untuk melihat seluruh atribut rincian dari kolom A sampai BM.
  5. Gunakan tombol Edit untuk mengubah data yang sebelumnya telah diperbarui.
  6. Gunakan tombol Ekspor ke Excel untuk mengunduh laporan detail pengisian dalam format spreadsheet.
